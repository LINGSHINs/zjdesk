# 书桌 (ShuZhuo) - 运营岗位资质刷题应用

一款精美的运营岗位资质刷题Web应用，支持Windows、Android、iOS多平台使用，可部署到GitHub Pages。

## ✨ 功能特性

### 📚 多种刷题模式
- **顺序刷题** - 按题号顺序系统学习
- **乱序模式** - 随机打乱顺序，加深记忆
- **组卷刷题** - 模拟考试，计时答题
- **按部门刷题** - 按部门分类专项突破
- **遗忘曲线记忆法** - 基于艾宾浩斯曲线智能复习
- **循环刷题** - 自定义题号范围，错题反复出现直到掌握
- **背题模式** - 先看答案再记忆
- **闪卡记忆** - 卡片翻转，间隔重复
- **快答模式** - 限时答题，锻炼反应速度
- **选题模式** - 答题卡视图，快速跳转
- **错题集** - 自动收集错题，针对性复习
- **收藏模式** - 收藏重点题目
- **每日一练** - 每日推送，养成习惯
- **游戏记忆模式** - 翻牌配对，趣味学习

## 🚀 部署到 GitHub Pages

### 方法一：直接上传
1. Fork 本仓库或创建新仓库
2. 将所有文件上传到仓库
3. 进入 Settings → Pages
4. Source 选择 main 分支根目录
5. 保存后等待部署完成

### 方法二：使用 Git
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main
```
然后在 Settings → Pages 中开启 Pages 服务。

## 📱 本地运行

### 方式一：使用 Python
```bash
cd shuzhuo
python3 -m http.server 8080
```
然后访问 http://localhost:8080

### 方式二：使用 Node.js
```bash
npx serve shuzhuo
```

### 方式三：使用 VS Code
安装 Live Server 插件，右键 index.html → Open with Live Server

## 🎯 彩蛋解锁方式

1. **Logo 点击法**：连续点击左上角Logo 10次
2. **科乐美秘籍**：输入 ↑↑↓↓←→←→BA
3. **成就解锁**：完成特定成就后自动解锁
4. **设置开关**：在设置面板中手动开启

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| 1-6 | 选择对应选项 |
| ↑ / ← | 上一题 |
| ↓ / → | 下一题 |
| Enter | 提交答案/显示答案 |
| Space | 答题卡 |
| Esc | 关闭弹窗 |
| Ctrl+S | 收藏/取消收藏 |
